# 第一性原理思维

沿用的假设受到质疑时，从有依据的事实、明确目标及必要约束出发重新考察做法。

## 方法

1. 说明实际目标，以及现有做法中受到质疑的部分。
2. 区分有依据的事实、暂定假设、惯例、自主选择的目标及约束，明确哪些约束固定、哪些可以改变。
3. 检查会改变结论的前提。听起来简单的前提仍然需要证据或明确约定。
4. 从保留的前提出发推导可行做法，复用仍然适用的已有知识，并保留用户的目标及授权范围。
5. 按当前决定关注的成本和后果比较方案。存在关键不确定性时，提出与问题相称的观察或实验，并在当前许可范围内执行。

## 结果

说明重要前提、需要修正的假设及由此得到的方案或取舍。明确表达自主选择的价值和目标。事实本身不足以决定用户应当重视什么。

新方案仍然需要适合实际环境，纳入会实质影响可行性的现实约束。

## 完成依据

对受质疑假设的检查已经足以支持当前决定时结束。继续追溯需要具体的未解决问题。
