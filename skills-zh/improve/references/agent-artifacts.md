# Agent 指引评估

通过实际任务中的使用结果，评价 Skill、提示词及其他 Agent 指引的改动。

## 明确比较对象

说明比较要解释哪项变化。比较指引版本时，保持模型、配置、输入及其他相关条件一致。部署组合的比较回答不同的问题，按组合记录并评价。

定义预期行为及必须保持的属性。选择自然任务，覆盖已报告的问题及本次变化可能影响的已确认边界。

使用任务预期的宿主和上下文。精简环境可以帮助调查具体原因，需要记录这种环境，并说明结论对实际使用的适用范围。

## 执行自然任务

给每次运行提供真实的用户请求及正常使用时会取得的上下文。评判指令和其他候选的身份保存在运行上下文之外。向评判者呈现不同方案时使用中性标识。

记录指引版本及实际运行条件。根据需要得出的结论安排足够的观察，考虑运行间的波动。将已经完成但表现不佳的输出保留在比较中。

区分执行故障、偏离约定流程及输出质量问题。重复运行时保留原始尝试及重跑原因。

## 检查证据

分别检查：

- **读取**：是否找到预期指引，是否读取要求的内容。使用宿主提供的实际会话或工具记录。
- **行为**：读取后执行了什么、产出了什么，依据任务要求及原始材料判断。

直接阅读成品，将重要发现追溯到支持它的材料。用原文核对模型评判者的事实判断，查明分歧后再采用其结论。

比较不同方案时使用相同标准，隐去无关的候选身份。向执行者要求正常的任务产物。根据观察到的行动及成果判断流程是否符合要求。

## 解释结果

归因时区分指引变化、模型变化和环境变化。结论保留实际观察条件。

将比较证据交回通用改进循环。完整读取、更长的指引或评判者的偏好都需要结合预期行为解释。
