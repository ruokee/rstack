# 降低理解负担

假设读者正在调查某个请求为什么采用特定超时值。他既需要找到值的来源，也需要知道哪些事实会改变它。每次间接引用增加一次查找，每项可变依赖增加一项需要记住的信息。

沿一个有代表性的问题追踪设计，观察读者在哪里需要离开当前操作、恢复远处的假设，或记住先前状态。短文件也可能依赖大量隐藏背景。几个职责清楚的模块可以使复杂操作更容易理解。

按边界省去了多少背景知识判断它。`read_timeout_seconds` 即使只有一个调用者，也可以合理承担毫秒 API 的单位转换。只给该操作改名的包装会增加一次查找。调用者数量提示复用情况，职责决定是否保留。

让状态归属清楚可见。限制值可以在何处、何时改变，显式传递相关输入。独立副本需要同步时，考虑从权威来源派生。读者便能根据操作契约确定适用的不变量。

文档也可以问同样的问题：读者能否一起找到规则及其条件，还是需要跨页面拼接片段？工作中选择证据时，参见[保护上下文](./protect-context.md)。
