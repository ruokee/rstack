# 保护上下文

有用的工作摘要保留能够改变下一项决定的事实。大批证据保留在可恢复来源中，当前工作只引入回答眼前问题所需的部分。

例如，对数千条记录进行迁移分析，可能需要不兼容的形状、出现频率，以及带来源位置的例子。"大部分记录正常"这样的摘要，会丢失决定迁移方式的例外。精确值及引文的形式重要时，保留原样内容。

用定向搜索、查询或有边界的提取取得相关资料。保留来源、选择条件、结论及未决问题，使后续矛盾能引回细节。判断需要完整背景时，读取完整材料。

批量提取有明确、可检查的结果，且任务角色和工具规则允许时，可以委派。重要判断由指定负责人承担。按信息需要拆分处理，同时保留完整约定范围。

让目标和必要约束在工作期间保持可用，分支细节在该分支相关时读取。较短上下文的价值在于保留正确完成工作所需的信息。
