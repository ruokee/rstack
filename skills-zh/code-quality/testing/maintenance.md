# 测试维护

维护测试需要权衡独立的行为保护、案例可读性、诊断价值及变化成本。类别名称只是调查线索，判断每项测试实际保护的保证。

## 脆弱断言

保持行为的重命名或拆分导致大量断言变化时，检查私有名称、内部形状或偶然调用顺序的耦合。将必要的准备调整与仅仅跟随实现的断言变化分开判断。

优先断言公共结果、错误、状态或真实边界交互。保护契约中的缓存选择或一次扣费的测试，有观察相应行为的合理依据。相关交互保证见[行为测试](./behavior.md)。

变更检测器测试镜像实现，缺少独立的正确性依据。指出其可能漏掉的合理错误，以及无害结构变化产生的维护噪声。依据下文的独特覆盖检查提出替换或删除建议。

## 案例可读性

让操作、决定结果的输入及期望值可以在局部理解。DAMP 强调有描述性且有意义的测试表达，允许帮助读者核对案例的重复。共享夹具及 builder 可以去掉无关构造细节，保留有意义的值。

Eager Test 混合无关保证，Mystery Guest 隐藏决定结果的数据或环境，General Fixture 准备远多于场景所需的状态，间接测试可能遮蔽被保护操作。指出具体问题及其阅读或维护成本。

真实多步流程可以需要大量准备及多个断言。一个结果的多个属性可以描述同一行为。保留这些场景，按需要改善失败信息及案例身份。断言轮盘赌表现为失败后仍难以识别被破坏的保证。

## 重复测试

合并或删除前比较保护的行为、边界条件、失败定位及独特场景。相同行覆盖、相同路径或相同突变分数，提供各自测量范围内的重叠证据。

同一保证且断言形状相同的案例可以参数化。参数会隐藏分支时，分别保留不同准备或错误语义。在最近的有效作用范围提取构造噪声，保留解释案例的输入及期望值。

重复契约值可能造成共同修改成本。共享期望值 helper 也可能复制生产算法，削弱独立性。核对共享的知识及其权威位置。

## 低价值检查

字面量镜像、getter 回显、框架转述及转发 mock 经常缺少独立的应用行为保护。指出保持这些测试通过时仍可能漏掉的消费者可见错误。应用特有的映射、错误处理或事务行为可以需要真实集成检查。

解析器、日期计算、转换或其他易错工具可以合理地拥有直接测试。配置的监管边界或协议常量可以是真实契约，并支持守卫测试。能体现保证时，优先执行配置产生的行为。保护已选择契约与复制偶然默认值具有不同价值。

## 修改

建议删除前确认测试贡献的独特行为、边界、失败诊断或文档场景，在建议结果中保留这些保护。测试修改沿用当前任务授权。可靠性问题见[测试可靠性](./reliability.md)。
