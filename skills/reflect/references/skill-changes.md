# Skill changes

Use these checks when a proposed improvement targets a Skill.

## Body

Find the version and content actually used in the session. Ground body changes in that use, then apply the existing-coverage criterion from [Synthesis](../SKILL.md#3-synthesize).

## Invocation

Check catalog visibility, invocation mode, and the actual loading record. Distinguish automatic discovery from explicit invocation.

Evaluate user-invoked Skills against the host's supported explicit calls. Propose a description change for an observed automatic-discovery problem where the Skill would have helped.

## New Skills

Prefer an existing home. Propose a new Skill when the pattern recurs, existing assets cannot carry it well, and it has a distinct responsibility and invocation need.
