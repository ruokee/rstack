# Exhaust the design space

Exploration is worthwhile when the remaining uncertainty can change the chosen design. Name that uncertainty and compare approaches that resolve it through different mechanisms.

For example, an editor must show diagnostics as a document changes. Immediate synchronous analysis and background analysis have different implications for typing latency, stale results, and implementation cost. Exercise the same editing sequence and document sizes in each. Cosmetic variants of one approach leave the scheduling question unresolved.

Set the binding constraints before comparing. Use the cheapest sketch, prototype, or focused experiment that reveals the decisive difference. Keep inputs and relevant conditions comparable, and explain which observations favor each option.

The alternatives determine how many experiments are useful. Stop when the evidence is strong enough for the consequence of the choice. A mechanical edit whose target and pattern are already established can proceed directly.

Choose within the confirmed goal and authorization. For methods of building and observing disposable alternatives, consult the `prototype` Skill.
