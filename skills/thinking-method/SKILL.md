# Thinking method

Choose a thinking method that helps answer the current question. Read the relevant branch before applying it. Combine branches when the question calls for them.

## Select a method

- **How**: explain a mechanism or trace behavior. Read [how](./references/how.md).
- **Why**: investigate causes, motives, or decision tradeoffs. Read [why](./references/why.md).
- **Analogy**: transfer understanding through shared relational structure. Read [analogy](./references/analogy.md).
- **Discuss**: develop a shared understanding of an open question. Read [discuss](./references/discuss.md).
- **Modeling**: clarify concepts, relationships, states, or constraints. Read [modeling](./references/modeling.md).
- **First-principle**: examine inherited assumptions and derive an approach from grounded premises. Read [first-principle](./references/first-principle.md).
- **Hypothesis**: make assumptions explicit, propose explanations, or explore hypothetical conditions. Read [hypothesis](./references/hypothesis.md).
- **Metacognition**: use evidence of confusion or ineffective work to adjust the current approach. Read [metacognition](./references/metacognition.md).

Select by the user's intent and the actual difficulty. A quoted term alone is not a request to apply its method. Start with the methods needed now; load another branch when a specific gap calls for it. A simple question can need only a short answer.

## Work within the question

Use available context and relevant evidence before asking for information. Separate observations, assumptions, and inferences. Keep user-confirmed goals and constraints fixed while examining approaches. Reopen them only when the user does. Preserve the user's preferences and authorized scope.

Local investigation and ordinary explanation belong in this work. For systematic source collection and synthesis, use an available research skill. For a learning activity organized around the learner's understanding, use an available teaching skill. Resolve their actual names and invocation rules from the host.

## Finish

Answer the question at the requested depth, with the evidence, assumptions, and limits that affect the conclusion. State an unresolved fact or choice when it materially changes the answer. End when the selected methods have served the current purpose. Further branches need a concrete reason.
