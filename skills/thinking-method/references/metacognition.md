# Metacognition

Adjust the current approach using observable evidence about understanding, progress, and errors.

## Method

1. Identify a concrete signal: a repeated mistake, conflicting evidence, stalled progress, a failed prediction, or a correction from the user.
2. Compare the intended outcome with the actual actions and results. Use visible plans, tool output, examples, and feedback as evidence.
3. Locate the relevant gap: missing knowledge, an unclear question, an unsupported assumption, a mistaken inference, or an unsuitable method.
4. Make a targeted adjustment. Reframe the question, obtain the missing evidence, change the representation, select another method, or ask for the indispensable input.
5. Check whether that adjustment addresses the original signal. Calibrate the conclusion and confidence to the evidence obtained.

## Result

Report the correction and its practical consequence when it matters to the user. Explain the evidence needed to judge it. Keep private reasoning private. An introspective narrative is not evidence of improved performance.

Keep this check proportionate to the problem. It serves the current task. Long-term learning or changes to persistent instructions need their own scope and authorization.

## Completion

Finish when the specific misunderstanding or ineffective approach has been corrected, or when the remaining obstacle and next useful action are clear. Resume the original task with the revised approach.
